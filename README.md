# assignment3_preprocessing.ipynb-pipeline.joblib-
A leakage-free ML preprocessing pipeline built on imbalanced credit data. Features stratified splitting, median imputation, percentile capping, categorical encodings, Yeo-Johnson deskewing, and RobustScaler. Quantifies leakage impact, balances the training set via SMOTE, and serializes the complete ColumnTransformer for production inference.
